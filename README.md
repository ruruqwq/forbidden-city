# 紫禁城 · 本宫在紫禁城死过108次

一款 PixiJS 古风宫斗网页游戏（第一章「初入宫闱」+ 第二章「深宫风云」），支持剧情分支、好感度、偏殿审问、小游戏与多结局。

## 在线游玩

启用 GitHub Pages 后，直接打开：
`https://ruruqwq.github.io/forbidden-city/`

## 本地运行

双击 `启动游戏.bat`（需 Node.js），或在本目录执行：

```bash
node server.js
```

然后浏览器打开终端提示的地址（默认 http://localhost:8901）。

## 说明

- 立绘、背景、事件图、BGM 与开场 PV 均为原创/自制素材。
- 存档保存在浏览器 localStorage。
