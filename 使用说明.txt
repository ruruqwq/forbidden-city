《本宫在紫禁城死过108次》· 本地离线版 使用说明
================================================

一、这是什么
本文件夹是一份完整的网页游戏《本宫在紫禁城死过108次》——高自由古风悬疑乙女向作品，
创作者：绵羊奶奶（原发布于「灵珠 AI」平台）。
现已把整站资源（代码、立绘、背景、事件图、BGM 与音效）全部搬到本地，
离线运行，不依赖原平台，原链接失效也能玩。

二、怎么玩（Windows）
1. 双击「启动游戏.bat」；
2. 会出现一个黑色命令行窗口，自动打开浏览器进入游戏；
3. 游戏过程中不要关闭这个黑窗口；
4. 玩完直接关掉黑窗口，服务即停止。

如果浏览器没自动打开，手动访问：http://localhost:8901

※ 请务必通过「启动游戏.bat」进入，不要直接双击 index.html。
  游戏用的是 ES module 架构，浏览器出于安全策略不允许从 file:// 直接加载模块，
  必须经由本地网页服务（bat 会自动帮你开好）。

三、怎么发布到网上（可选）
整个「紫禁城」文件夹就是成品，纯静态、不需要数据库和后端。
把它原样上传到任意静态站点托管即可（GitHub Pages / Vercel / Netlify /
阿里云 OSS / 腾讯云 COS / 宝塔面板等）。玩家用网址访问，手机电脑都能玩。
提示：存档保存在玩家自己浏览器的 localStorage 里，跟发布在哪台服务器无关。

四、目录结构
  index.html          游戏入口页
  启动游戏.bat        本地启动器（自动开本地服务 + 打开浏览器）
  server.js           备用启动脚本（没装 Python 时用：node server.js）
  storage.js          存储隔离 shim（原平台自带，勿改）
  fusion.js           原平台 JSAPI（原平台自带，勿改）
  assets/             全部游戏资源（130 个文件）
    ├─ index-*.js / *.js   游戏程序（含 Pixi 渲染引擎分块）
    ├─ index-*.css         样式
    ├─ nv_zhu*.png 等 23 张   人物立绘
    ├─ bg_*.jpg           场景背景（13 张，含 4K 宫门、宫城地图）
    ├─ ev_*.jpg           探案线索 / 事件插图（30 张）
    ├─ bgm_*.mp3          背景音乐（16 首）
    └─ sfx_*.mp3          操作音效（8 个）

五、已做的本地化处理
1. 移除原平台的分享外壳（顶部导航条、评论区、右下角浮标、AI 标识、
   加载页等），只保留游戏本体；
2. 所有跨域 CDN 依赖改为本地文件，断网可正常运行；
3. 补全了原站自检会报错的 wei_yanchi_2.png 立绘，游戏的「立绘自检」不再报警；
4. 用 Edge 无头浏览器实测：进入标题屏 → 宫城地图 → 正殿开局 → 剧情推进，
   全程 0 个资源加载失败。

六、已知说明（不影响游玩）
· 「登录 / 存档上云」「真人匹配五子棋」属于原平台的联网功能，
  离线状态下不可用；本地存档、剧情、图鉴、小游戏等单机内容不受影响。
· 若系统里 Python 和 Node.js 都没有，启动器会提示安装 Python。
